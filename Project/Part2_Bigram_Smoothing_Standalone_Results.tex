\subsubsection{Experimental Results}

The TF-IDF + add-one-smoothed unigram-bigram hybrid system was evaluated on the Cranfield dataset using the same preprocessing pipeline as the baseline TF-IDF model: Punkt sentence segmentation, Penn Treebank tokenization, Porter stemming, and NLTK stopword removal.
The standalone model adds phrase-aware bigrams of the form \texttt{boundary\_layer} and combines the baseline TF-IDF cosine score with add-one-smoothed unigram and bigram bonuses.
The interpolation weights used were $0.1$ for unigram smoothing and $0.1$ for bigram smoothing, which was the best-performing setting among the earlier tested variants.
Evaluation metrics were computed for values of $k$ ranging from 1 to 10.

The Wilcoxon signed-rank test was conducted separately for:

\begin{itemize}
    \item Precision@k
    \item Recall@k
    \item F$_{0.5}$@k
\end{itemize}

for all values of $k$ from 1 to 10.\\

The null hypothesis used was:

H0: \texttt{There is no statistically significant difference between the baseline TF-IDF system and the standalone TF-IDF + add-one-smoothed unigram-bigram hybrid retrieval system.}

The alternative hypothesis was:

H1: \texttt{The standalone TF-IDF + add-one-smoothed unigram-bigram hybrid system produces statistically significant retrieval improvements over the baseline TF-IDF system.}\\

A significance threshold of:

\[
\alpha = 0.05
\]

was used.

Compared with the baseline TF-IDF run, Precision@1 increased from $0.6844$ to $0.7422$, Precision@3 increased from $0.5111$ to $0.5393$, MAP@10 increased from $0.3467$ to $0.3606$, nDCG@10 increased from $0.4709$ to $0.4865$, and MRR@10 increased from $0.7687$ to $0.8073$.
The Wilcoxon analysis shows statistically significant improvements at $k=2, 3$ for Precision@k, Recall@k, and F$_{0.5}$@k.
The results indicate that phrase-aware evidence combined with add-one smoothing on lexical unigrams and bigrams improves early retrieval quality more reliably than the unigram-only TF-IDF baseline, while still preserving the original preprocessing pipeline.
